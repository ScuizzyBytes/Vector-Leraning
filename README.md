# 🌌 Custom Vectors & 3D Space Engine (Python)

Репозиторий, посвященный глубокому изучению линейной алгебры, созданию кастомных векторных классов (`Vector2D`, `Vector3D`) и написанию трёхмерного графического движка с нуля на Python и Pygame.

---

## 📂 Структура проекта

* **`Vector2D.py`** — Двумерный векторный класс, реализующий базовую математику осей $X$ и $Y$, сложение и вычитание.
* **`Gemini_Vector3D.py` / `Gemini_Vector3DV2.py`** — Трёхмерные векторные архитектуры с поддержкой глубины ($Z$) и вычислением длины векторов по теореме Пифагора.
* **`main.py`** — Главный скрипт симуляции звёздного гипердрайва (Warp Speed), связывающий кастомную математику с графическим рендерингом в реальном времени.

---
